## 用户给的原生命令在这台机器上跑不通

按用户命令原样启动（系统安装的插件 `plugin_env_0906/vllm-plugin-FL`）可以起来，但第一个 `/rerank` 请求就让 EngineCore 退出：

```
File ".../plugin_env_0906/vllm-plugin-FL/vllm_fl/worker/worker.py", line 943, in execute_model
    assert isinstance(output, IntermediateTensors)
AssertionError
```

pooling 模型返回的是异步输出，这个版本的插件没有处理。工作区 `minimax-m3-coverage-80` 在 bge-m3 适配时已修（pr/11 worker 修复）。因此用户给的 1k 8995 / 4k 8186 tok/s 不是这台机器、这个插件跑出来的；同机即使只让 attention 走 FlagGems 也只有 1k 8005 / 4k 5898。

所以本报告的参考配置 = 工作区插件 + `VLLM_FL_FLAGOS_WHITELIST=attention_backend`（其余为 torch / Inductor / cuBLAS），其余参数与用户命令完全一致。这与 bge-m3、Qwen3-VL-Embedding 的做法相同。

GPU 6 被容器外的进程占用（88 GB），参考跑在 GPU 4，本配置跑在 GPU 7，两者同时压测。

## 启动命令

```bash
cd /mnt/cpfs/xiangbin/codex/minimax-m3-coverage-80
export CUDA_VISIBLE_DEVICES=7
export PYTHONPATH=/mnt/cpfs/xiangbin/codex/minimax-m3-coverage-80
export VLLM_DISABLE_COMPILE_CACHE=1
export VLLM_FL_FLAGOS_BLACKLIST_APPEND=mm,mm_out,addmm,addmm_out,linear,empty
export VLLM_FL_Q3VLEMB_STABLE=1
export VLLM_FL_Q3VLEMB_DENSE=hybrid
export VLLM_FL_Q3VLEMB_GEMS_SMALL_M=512

vllm serve /mnt/cpfs/xiangbin/Qwen3-Reranker-8B/ \
  --served-model-name Qwen3-Reranker-8B --runner pooling --port 18343 \
  --max-model-len 32768 --gpu-memory-utilization 0.9 --no-enable-prefix-caching \
  --hf_overrides '{"architectures": ["Qwen3ForSequenceClassification"],"classifier_from_token": ["no", "yes"],"is_original_qwen3_reranker": true}' \
  --chat-template /opt/vllm/examples/pooling/score/template/qwen3_reranker.jinja
```

脚本方式：`tools/ppu/qwen3_reranker/serve_qwen3_reranker.sh <run_dir> <gpu> <port> worktree`（环境变量照上设置；参数与用户命令一致）。

Reranker 的 LLM 与 Qwen3-VL-Embedding-8B 的 LLM 结构完全相同（hidden 4096、intermediate 12288、32/8 头、无 bias），所以直接复用 `vllm_fl/optimizations/ppu/qwen3_vl_embedding/` 的开关，没有新增模型代码：

| 变量 | 作用 |
|---|---|
| `mm,mm_out,addmm,addmm_out,linear` 拉黑 | 8B 稠密模型以 GEMM 为主，FlagGems GEMM 在 M ≥ 1024 时比 cuBLAS 慢 12–26% |
| `empty` 拉黑 | FlagGems `empty` 每次调用有固定 CPU 开销 |
| `VLLM_FL_Q3VLEMB_STABLE=1` | 池化取行用的 `aten.index`、`copy_` 换成形状稳定版本，避免每个 batch 重新生成 kernel |
| `VLLM_FL_Q3VLEMB_DENSE=hybrid` + `GEMS_SMALL_M=512` | ≤ 512 token 的 batch，4 个投影走调好 tile 的 FlagGems linear（与 cuBLAS 持平）；更大的走 cuBLAS |
| `VLLM_DISABLE_COMPILE_CACHE=1` | vLLM 编译缓存的 key 不看 `VLLM_FL_*` |

Qwen3-VL-Embedding 里需要拉黑的三个 flash attention 入口这里不需要：Reranker 是纯文本，head_dim 128，不走 SDPA。

